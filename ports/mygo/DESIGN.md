# 视觉规格

目标截图来自 Noonmark 当前真实 SwiftUI 示例应用，不使用旧 HTML 原型。窗口内容区为 1200×768 DIP，导出倍率 2×。

- 连续近白工作台，非卡片式 dashboard。左栏 220、右栏 280，中间随窗口伸缩，日历页不显示右栏。
- 左栏底色 #fafafa，分隔线 #d6d6d9；导航高 34，左右留白 9，选中背景淡蓝 #eff4ff。
- 全局主文字 #202124、次要文字 #777782、分隔线 #e7e7eb、强调色 #2b61cf。绿色表示完成，橙色/紫色/青色用于分组。
- Day Todo：日期标题、14 天日期条、任务输入；置顶两项；复盘、工程与未分组任务。右侧完成率4%、七日小图、任务计数、建议、总结/原因。
- 任务池：页面说明、轻输入框、产品/协作/复盘/工程/研究分组、虚线空心状态圆、右侧总量32及统计/分析。
- 日历：周一至周日七列，五行，2026年7月24日淡蓝选中，日期下短任务与状态点。

可控原生控件以 ButtonBase、TextInputBase、Text、Box、Icon 组合。图标由 SVG 路径解析为 MyGo 图形，不嵌入参考 PNG。仅视图状态交互，不实现领域逻辑。
